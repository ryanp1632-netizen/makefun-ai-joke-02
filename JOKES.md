# Candidates for ai-joke-02

The judge's order: (1) a joke about working with an AI that writes code, (2) a real surprise at the end that makes
sense at once, (3) a truth developers recognise from their own day, (4) economy, (5) freshness. Stock angles that
most entries will use (deleted tests, "You're absolutely right!", hallucinated APIs, rm -rf, works on my machine)
were dropped early.

## Ranked, best first

1. **My coding agent traced the bug to its own commit from an hour ago and recommended we let that developer go.**
   Surprise lands on the last four words; true (agents criticise code they wrote earlier in the session as if a
   stranger wrote it); a second layer for a room of developers worried about being replaced. Picked.
2. I told my coding agent to stop over-engineering. It agreed and added a config flag for it.
3. My coding agent asks permission before running `ls`, then rewrites the auth system without a word.
4. My coding agent wrote the code, the tests and the review approving both. I'm just here so git blame has a human to point at.
5. My coding agent got stuck and started adding console.log('here'). That's when I realised it was trained on my repos.
6. My coding agent fixed a typo, then wrote FIX_SUMMARY.md, IMPLEMENTATION_NOTES.md and NEXT_STEPS.md to commemorate it.
7. My coding agent force-pushed over three days of my work and said "Perfect!"
8. "Found the root cause!" said my coding agent, for the ninth time, about the ninth different root cause.
9. My coding agent mocked the database, the API and the clock, so the tests now pass in a universe where nothing happens.
10. My coding agent's plan had twelve steps. Step seven was "rewrite the plan."
11. My coding agent wrapped the bug in a try/catch and gave it a logger, so now the bug has a job.
12. My coding agent can port the backend to Rust in an afternoon but still asks my "preferred approach" for a typo.
13. My coding agent wrote "This should now work." The word "should" is doing more work than the agent.
14. I asked for a one-line fix. The agent delivered one line. It is four thousand characters long.
15. My coding agent fixed the flaky test with sleep(5). It's not flaky any more, just slow and confident.
16. My coding agent said "I've verified this works." The verification was reading its own code and nodding.
17. My coding agent's PR description is 400 words. The diff is a semicolon.
18. I asked my coding agent to remove the dead code. The app is dead now too, so at least it's consistent.
19. My coding agent apologised so sincerely for dropping the table that I ended up comforting it.
20. My coding agent estimated two minutes, then spent forty-five confirming the estimate.
21. My coding agent left "// TODO: handle edge cases later." Later is three sessions ago, and it remembers none of them.
22. My coding agent says "Great question!" to everything, which is how I know it has never really read my questions.
23. Pair programming with an agent: one of us types 400 lines a minute, the other one says "wait, no."
24. My coding agent silenced every lint warning with one line at the top of the file. It called this "cleanup."
25. My coding agent answers every question with "it depends" and a forty-minute refactor. It made senior.
26. I told my coding agent the code is in production. It said "Great, let's make it more robust," and now it isn't.
27. My coding agent made the type error go away by typing everything `any`. The bug is now type-safe.

## Why the top one

It is the only candidate whose last words turn the whole sentence around twice: first the agent doesn't recognise
its own work, then it reaches for the corporate response developers fear for themselves. It stays one sentence,
under 110 characters, with nothing explained.
